## Featherless

**Featherless** is a narrative-driven adventure game developed using **Love2D** for the **UPCS Game Jam**.  

Follow Duckie, a young duck who is told that his bloodline is cursed and that he can never swim. Armed with a mysterious journal listing strange ingredients, Duckie embarks on a journey to uncover the truth about his family and break the curse.

---

## Game Mechanics

- Walking and sprinting  
- Stealth and hiding from enemies  
- Enemy detection system  
- Defending against **Ash Owls** using a stick  
- Fishing mini-game  
- Interactive objects and environment  

---

## How to Run the Game

### Requirements
- **Love2D** (latest version recommended)  
  Download from: https://love2d.org

---

### Running via Terminal (All Platforms)

1. Download or clone this repository
2. Open a terminal inside the game folder
3. Run:
   ```bash
   love .
   ```

---

### Quick Test
```bash
# Navigate to game folder
cd featherless
love .
```
